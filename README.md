# TiMa Launcher — اسکلت اپ اندروید (POC)

## این چیست؟
یک پروژهٔ اندروید کامل (Kotlin) با هویت بصری تیما و سه تایل: **بازی**، **نرم‌افزار**، **هوش**.
این اپ خودش هیچ استریمی انجام نمی‌دهد — فقط پوسته/ناوبری است:
- تایل «بازی» و «نرم‌افزار» → یک Session روی سرویس ابر فردوسی باز می‌کنند و نتیجه (که فرض شده یک لینک وب‌محور/Viewer است) را تمام‌صفحه نمایش می‌دهند.
- تایل «هوش» → یک صفحهٔ چت سادهٔ متنی که به یک API مدل زبانی وصل می‌شود.

## قبل از هرچیز باید باز کنید و بسازید
این کد را نمی‌شود بدون Android Studio کامپایل کرد (نیاز به Android SDK و دانلود وابستگی‌ها از اینترنت دارد که در محیط من در دسترس نبود؛ کد از نظر نحوی/ساختاری بررسی و تمیز نوشته شده، اما کامپایل واقعی را باید روی سیستم خودتان انجام دهید):

```bash
# 1. Android Studio را باز کنید → Open → پوشهٔ tima-launcher را انتخاب کنید
# 2. صبر کنید Gradle Sync کامل شود (نیاز به اینترنت دارد)
# 3. یک Android TV Box یا شبیه‌ساز را وصل/روشن کنید
# 4. Run ▶ را بزنید
```

## دقیقاً کجا باید ویرایش کنید؟

فقط دو فایل نیاز به اطلاعات واقعی از ابر فردوسی و بک‌اند شما دارند — همه‌جا با `TODO` علامت‌گذاری شده:

| فایل | چه چیزی باید عوض شود |
|---|---|
| `StreamConfig.kt` | آدرس API، کلید احراز هویت، و شناسهٔ Appهای «بازی» و «نرم‌افزار» ابر فردوسی |
| `AiChatActivity.kt` | آدرس بک‌اند شما برای سرویس چت (توصیه: تماس با مدل زبانی از سمت بک‌اند خودتان انجام شود، نه مستقیم از داخل اپ، تا کلید API لو نرود) |

**فرض اصلی کد:** ابر فردوسی برای هر Session یک URL قابل‌نمایش در مرورگر/WebView برمی‌گرداند (رایج‌ترین روش برای این نوع سرویس‌ها). اگر آن‌ها به‌جایش یک SDK اندرویدی اختصاصی می‌دهند، باید `StreamActivity.kt` را طوری تغییر دهید که به‌جای `WebView`، از View همان SDK استفاده کند — کل بقیهٔ اپ (تایل‌ها، ناوبری) دست‌نخورده می‌ماند.

## راه‌اندازی حالت Kiosk (بوت مستقیم به تیما)

بعد از نصب اپ روی اندروید باکس:
1. تنظیمات باکس → Apps → Default apps → Home app → **TiMa** را انتخاب کنید.
2. باکس را ری‌استارت کنید — باید مستقیم وارد صفحهٔ سه‌تایلی تیما شود.
3. (اختیاری، برای قفل‌کردن کامل) اکثر Android TV Boxها یک اپ Kiosk/Launcher-Lock دارند که می‌توانید با آن دسترسی به دکمهٔ Home اصلی اندروید را کاملاً مسدود کنید.

## نکات مهم

- **بدون روت:** این روش (ثبت اپ به‌عنوان HOME + Launcher) روی اکثر Android TV Boxهای بازاری بدون نیاز به روت کار می‌کند.
- **امنیت کلید API:** کلید API مدل هوش مصنوعی را هرگز مستقیم داخل اپ اندروید قرار ندهید (قابل استخراج از APK است). حتماً از طریق یک بک‌اند واسط تماس بگیرید — همان‌طور که در کد یادداشت شده.
- **تست شبکهٔ واقعی:** حتماً روی اینترنت واقعی خانه/دفتر تست کنید، نه شبکهٔ داخلی سرور، تا KPIهای واقعی (بخش ۱۳ سند SRS) به‌دست بیاید.

## گام بعدی پیشنهادی
وقتی آدرس/فرمت واقعی API ابر فردوسی را گرفتید، همین فایل `StreamConfig.kt` را با آن اطلاعات به من بدهید تا دقیق‌تر تکمیلش کنم.
